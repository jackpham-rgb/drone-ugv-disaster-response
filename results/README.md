# Results

Generated by the scripts in `scripts/`, not hand-edited. Regenerate with:

```bash
python -m scripts.train_ippo    # ippo_seed*.json
python -m scripts.make_plots    # learning_curve.png
python -m scripts.plot_voronoi  # voronoi.png
```

| File | From |
|---|---|
| `ippo_seed0.json`, `ippo_seed1.json`, `ippo_seed2.json` | `scripts/train_ippo.py`: (env steps, mean episode return) pairs for each of 3 training seeds |
| `learning_curve.png` | `scripts/make_plots.py`: the 3 seeds above, mean with a 95% confidence band |
| `ippo.pt` | a saved policy checkpoint, if trained with `torch.save` (see `docs/research_elevation.md`) |
| `demo.gif` | `scripts/render_rollout.py`: one rollout of a saved checkpoint |
| `voronoi.png` | `scripts/plot_voronoi.py`: an example Voronoi coverage partition |
| `table.csv`, `ablation.png` | `scripts/results_table.py`, once baseline and ablation runs exist |
